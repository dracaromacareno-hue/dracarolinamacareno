## Reglas para no volver a llenarse de documentos

1. **Un documento por tema, no uno por sesión.** Si ya existe uno sobre eso, se actualiza, no se crea otro.
2. **Los documentos no llevan el historial de correcciones.** Si algo resultó ser falso, se corrige el texto y ya. Lo que se pensó y se descartó no se documenta.
3. **Fecha en el nombre solo cuando es una foto de un momento** (auditorías, listados de leads). Los planes vivos van sin fecha en el nombre y con "actualizado" adentro.
4. **Cuando un documento queda superado, se marca 📁 aquí** y se deja de tocar. No se borra: explica por qué se tomó una decisión.
5. **Este índice se actualiza cada vez que nace o muere un documento.**
